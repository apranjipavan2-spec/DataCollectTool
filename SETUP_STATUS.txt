================================================================================
                      OFFLINE FEATURE DETAILS
================================================================================

How Offline Works:
  1. Forms cached locally on device (OPFS/IndexedDB)
  2. Data auto-saves every 300ms as you type
  3. Photos auto-compressed to 200KB
  4. Audio recorded at low bitrate (24kbps)
  5. When online → automatic background sync
  6. Supervisor sees submissions on dashboard

Network Requirements:
  - 2G/3G/4G/WiFi all supported
  - Text submission: ~2KB (2-3 seconds on 2G)
  - Photo: ~200KB (8-12 seconds on 2G)
  - Audio 30s: ~100KB (5-8 seconds on 2G)

Data Security:
  - Encrypted storage on device
  - Password-protected login
  - Multi-tenant isolation
  - HTTPS ready

================================================================================
                         API ENDPOINTS
================================================================================

Authentication:
  POST /auth/login → Get JWT token

Forms:
  GET /forms/ → List forms
  POST /forms/ → Create form

Submissions:
  GET /submissions/ → List submissions
  POST /submissions/ → Create submission
  PATCH /submissions/{id} → Flag/review

Sync:
  POST /sync/push → Push pending data
  POST /sync/media → Upload photos/audio

Export:
  GET /export/submissions/{id}/csv → Download CSV
  GET /export/submissions/{id}/dta → Download Stata

API Keys:
  POST /api-keys/ → Generate key
  GET /api-keys/ → List keys
  DELETE /api-keys/{id} → Revoke key

Full docs: http://localhost:8000/docs (interactive Swagger UI)
