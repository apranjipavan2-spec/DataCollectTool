📋 Project Overview

FieldPulse is a B2B offline-first SaaS platform designed for field data collection in India. It competes directly with SurveyCTO ($225-630/month) but costs only ₹18,000/month (~$215).

Key Advantages

✅ True Offline

Works perfectly without internet. All data saved locally. Auto-syncs when reconnected.

📸 Smart Media

Automatic photo compression (5MB→200KB). Audio recording built-in. Supports barcode scanning.

⚡ Background Sync

Service Worker syncs data in background. App doesn't need to be open. Works on 2G speeds.

🗂️ Form Flexibility

15 field types. Complex skip logic. Repeat groups. Multi-language support (EN/HI/KN/TE).

👥 Team Management

Assign specific forms to specific enumerators. Real-time dashboard. Submission flagging.

📊 Export Ready

CSV, Stata (.dta), and other formats. Works with research teams and data analysts.

Tech Stack

Frontend: React 18 + TypeScript + Vite + PWA
Backend: FastAPI + SQLAlchemy + PostgreSQL
Storage: wa-sqlite (OPFS) + Dexie.js (IndexedDB)
Cloud: Google Drive for media, Firebase for 2FA (future)

📖 How to Use FieldPulse

For Enumerators (Field Staff)

Step 1: Download & Install

Open the app link on your phone (Android 8+). Add to home screen or download from Play Store (via TWA). No need for Play Store account.

Step 2: Login

Enter your phone number and password. Keep your password secure — don't share it with anyone.

Step 3: View Assigned Forms

You'll see only the forms assigned to you by your supervisor. Other forms are hidden.

Step 4: Collect Data

Tap a form → answer questions one at a time → auto-saves to your phone. Complete it offline, with or without internet.

Step 5: Submit

When ready, tap "Submit". Data is saved locally first. When you have internet, it automatically syncs to the server.

Step 6: Check Sync Status

Look for the sync icon — if it's spinning, data is uploading. If it's green, all good. If red, you'll retry automatically when connected.

For Supervisors

Step 1: Access Dashboard

Login with your supervisor account. You'll see the dashboard with all submissions from your team.

Step 2: Monitor Submissions

View count by enumerator. Click any submission to see full details, GPS location, timestamps, and photos.

Step 3: Flag & Review

Click the flag icon on any submission. Add a note (e.g., "Needs clarification", "Rejected"). Enumerator will see your feedback.

Step 4: Assign Forms

Go to Forms tab → click "Assign". Select form → select enumerators → save. Only those enumerators will see this form.

Step 5: Manage Team

Team tab → Add/remove users → assign roles (Enumerator, Supervisor, Admin). Deactivate inactive staff.

Step 6: Export Data

Select submissions → Download as CSV or Stata (.dta). Ready to analyze in Excel or R.

For Admins

Step 1: Create Forms

Go to Form Builder. Add fields (text, photos, audio, GPS, rating, etc.). Set skip logic. Create sections.

Step 2: Configure Permissions

Admin panel → Users → set roles (Enumerator, Supervisor, Admin). Only admins can delete forms.

Step 3: View Analytics

Dashboard → Overview → see submission counts, top enumerators, submission trends over time.

Feature Highlights

📸 Taking Photos

Tap the camera icon. Take a photo. Auto-compressed to 200KB for fast upload. Can retake if needed. Works offline — stored locally, syncs when connected.

🎵 Recording Audio

Tap the microphone icon. Record your voice. Low bitrate keeps file size small (~60KB per 30s). Playback before submit. Same sync as photos.

📍 GPS Location

When asking for location, app captures GPS coordinates. Works with no internet (uses device GPS). View on map in the dashboard.

🔄 Repeat Groups

Some forms have repeating sections (e.g., list 5 household members). Tap "Add" to create rows. Fill each row. Remove if needed.

📊 Skip Logic

Questions appear/hide based on previous answers. E.g., "Do you have a phone?" → If No, skip the next 3 questions.

🔗 API Reference

Base URL

http://localhost:8000/api/v1

🔐 Authentication

POST /auth/login

Login with phone and password. Returns JWT token.

{
"phone": "+919999990001",
"password": "test@123"
}

Response:
{
"access_token": "eyJ0eXAi...",
"token_type": "bearer",
"user": { "id": "...", "phone": "...", "role": "master_admin" }
}

📋 Forms

GET /forms/

List all forms (for enumerator: only assigned forms). Supports pagination.

Query params: page=1, page_size=10
POST /forms/

Create a new form. Admin only.

📝 Submissions

GET /submissions/

List submissions. Supervisors see their team's data. Enumerators see only their submissions.

Query params: page=1, page_size=20, date_from=2026-01-01, date_to=2026-12-31
POST /submissions/

Create a new submission (locally saved first, then synced).

PATCH /submissions/{id}

Flag a submission or update its status.

{
"flag_note": "Needs clarification",
"status": "flagged"
}

🔄 Sync

POST /sync/push

Push submissions to server. Two-phase: text-only first (photos removed), then media.

POST /sync/media

Upload a single photo or audio file (multipart form data).

Fields: submission_id, field_name, file_type (photo/audio), file (binary)

👥 Users & Team

GET /users/

List team members. Pagination supported.

Query params: page=1, page_size=50
POST /users/

Create a new user. Admin/Supervisor only.

{
"phone": "+919999990099",
"name": "Rahul Kumar",
"role": "enumerator",
"password": "secure_password_here"
}

📊 Export

GET /export/{form_id}/csv

Export all submissions for a form as CSV.

GET /export/{form_id}/stata

Export as Stata .dta format for research analysis.

🎯 Form Assignments

GET /assignments/

List all form assignments.

POST /assignments/

Assign a form to enumerators.

{
"form_id": "uuid-here",
"enumerator_ids": ["uuid1", "uuid2", "uuid3"]
}
