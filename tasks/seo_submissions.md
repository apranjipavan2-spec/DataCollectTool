## 1. Google Search Console (HIGHEST PRIORITY — 30 min)

**URL:** https://search.google.com/search-console

1. Sign in with the Gmail that owns `fieldgovern.com`
2. Click **"Add property"** → choose **"Domain"** (not URL prefix)
3. Enter: `fieldgovern.com`
4. Google gives you a TXT record like:
   `google-site-verification=AbCdEfGh1234567890...`
5. **DNS provider step** (depends on where you bought fieldgovern.com):
   - **GoDaddy:** My Products → DNS → Add Record → Type: TXT, Name: `@`, Value: paste the string
   - **Namecheap:** Domain List → Advanced DNS → Add New Record → TXT, Host: `@`, Value: paste
   - **Cloudflare:** DNS → Add Record → TXT, Name: `@`, Content: paste
   - **Google Domains / Squarespace:** DNS → Custom Records → Type: TXT, Data: paste
6. Wait 5–30 min, click **Verify** in GSC
7. Once verified → **Sitemaps** (left sidebar) → submit `https://www.fieldgovern.com/sitemap.xml`
8. **URL Inspection** → paste each URL → click **Request Indexing**:
   - `https://www.fieldgovern.com/`
   - `https://www.fieldgovern.com/features.html`
   - `https://www.fieldgovern.com/pricing.html`
   - `https://www.fieldgovern.com/surveycto-alternative.html`
   - `https://www.fieldgovern.com/use-cases.html`
   - `https://www.fieldgovern.com/integrations.html`
   - `https://www.fieldgovern.com/security.html`
   - `https://www.fieldgovern.com/about.html`
   - `https://www.fieldgovern.com/demo.html`
