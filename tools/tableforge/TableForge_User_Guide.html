Getting Started

TableForge is a desktop analytics workbench that turns raw Excel or CSV data into publication-ready pivot tables, statistical reports, and charts — all without writing any code.

  1. Launch the Application
    Run python launcher.py from the C:\DCT\tableforge\ folder. This starts both the backend (port 8000) and frontend (port 5173) servers automatically. Your browser opens TableForge.
  2. Import Your Data File
    Click Import Excel or CSV File on the welcome screen, or drag-and-drop your file. Supported formats: .xlsx .xls .csv .tsv
  3. Drag Columns into Zones
    From the Source Panel on the left, drag column names into the Rows, Columns, or Values drop zones.
  4. Your Table Appears Instantly
    The pivot table is automatically generated and appears in the Live Preview panel. Any change you make is reflected immediately.
  5. Format, Analyze & Export
    Use the ribbon tabs to apply themes, run statistical tests, build charts, and export to Excel, CSV, or PDF.
💡
Tip: You can import multiple sheets from an Excel file. TableForge will ask which sheet to use and shows a data preview before building any table.

Context-sensitive toolbar that changes based on the active ribbon tab. Contains buttons for all major actions like Totals, Filters, Sort, Export, etc.

🎨

Slide-out panel for themes, fonts, borders, colors, and all visual formatting. Open via Format tab or the ribbon Format button.

🗂️

Table Tabs (Bottom)

Each table is a tab at the bottom. Create multiple tables from the same dataset. Right-click a tab to duplicate or delete.

📟

Status Bar

Shows dataset name, row count, active table result count, and keyboard shortcut hints. Located at the very bottom.

Building Tables

Drop Zones

The three drop zones are the heart of TableForge. Think of them like an Excel PivotTable field list.

ZoneBadgePurposeExample
Rows R Categorical groups down the left side State, Gender, Department
Columns C Categorical groups across the top Year, Quarter, Category
Values V Numeric measures to summarize Sales, Count, Revenue
🔄
Reorder: Drag items within a zone to reorder them. Drag them out to remove. Multiple fields in Rows creates hierarchical sub-groups.

Aggregation (Summarize By)

Click on any field in the Values zone to choose how it is summarized:

FunctionDescription
CountNumber of non-null values
SumTotal of all values
MeanAverage (arithmetic mean)
MedianMiddle value
MinSmallest value
MaxLargest value
StdStandard deviation
VarVariance
% of TotalEach cell as % of grand total
% of RowEach cell as % of its row total
% of ColumnEach cell as % of its column total
Combo (Count + %)Shows count on line 1, percentage on line 2 in parentheses

Show Values As (Running Calculations)

Additional display transformations applied after aggregation:

  • None — raw aggregated value
  • % of Grand Total — cell ÷ overall total
  • % of Row Total — cell ÷ row total
  • % of Column Total — cell ÷ column total
  • Running Total — cumulative sum across rows
  • Rank — rank of each value (1 = highest)

Filter Panel

Filters restrict which source rows are used in tabulation. They do not modify your original data.

  • Text filter — include/exclude specific category values
  • Numeric range — e.g., only rows where Age > 18
  • Date range — filter by start and end date
  • Multiple filters stack (AND logic)
  • Filters are saved per-table — different tables can have different filters

Ribbon — Statistics Tab

Run advanced statistical analyses on your dataset directly from TableForge — no SPSS or R required.

📊

Descriptive Statistics

Mean, median, mode, std dev, variance, skewness, kurtosis, quartiles for all numeric columns.

🔗

Correlation Matrix

Pearson/Spearman correlation coefficients between numeric variables. Color-coded heatmap display.

🔀

Cross-tabulation

Chi-square test of independence between two categorical variables with expected frequencies.

⚖️

T-Test

Independent samples and paired t-test. Select group variable and value variable. Shows p-value and significance.

🧪

ANOVA

One-way analysis of variance across multiple groups. F-statistic, p-value, and post-hoc comparisons.

📉

Regression

Simple and multiple linear regression. R², coefficients, p-values, and residual analysis.

📐

Normality Tests

Shapiro-Wilk and Kolmogorov-Smirnov tests. Helps decide which statistical tests are appropriate.

🔎

Outlier Detection

IQR method and Z-score method to identify outlier rows in numeric columns.

📋

Frequency Table

Value counts, cumulative frequency, and percentage distribution for categorical columns.

📌
Export Stats: Statistical test results can be copied or exported along with your main tables for inclusion in reports.

Source Panel

The Source Panel on the left side lists all columns from your dataset.

  • Search box — type to filter columns by name. Matching text is highlighted in yellow.
  • IN TABLE section — shows only columns currently used in the active table, with zone badges R C V
  • Drag to drop zones — drag any column to the Rows, Columns, or Values zone
  • Multi-select — hold Shift or Ctrl to select multiple columns and drop them all at once
  • Column type icons — 123 for numeric, Abc for text, 📅 for date columns
  • Custom columns — metrics and bins you create also appear here
🎨

Format Panel

Open via Format tab → Open Format Panel. Three tabs give you full control over table appearance.

Tab 1 — Appearance

  • Theme Presets — choose from Default (dark), Corporate Blue, Minimal B&W, Financial, Government, Teal. Selecting a preset resets all custom colors.
  • Font Family — choose from Times New Roman (default), Arial, Calibri, Georgia, and more
  • Font Size — default is 12pt for table content
  • Bold / Italic — toggle for title text
  • Border Style — None, Thin, Medium, Thick, Booktabs
  • Zebra Stripes — alternating row background colors for readability

Tab 2 — Content

  • Background Colors — set separate colors for: Header Row, Row Labels, Values Area, Grand Total Row, Header Text
  • Conditional Formatting — color cells based on value thresholds (e.g., values > 1000 show in green)
  • Heatmap — gradient color scale across all value cells (lowest=blue, highest=red)
  • Header Renames — rename any column header without changing source data
  • Table Number — auto-number tables (Table 1, Table 2 …) with custom prefix
  • Footnote — add a footnote text below the table

Tab 3 — Advanced

  • Serial Numbers — add row numbers (continuous or per-group)
  • Freeze Columns — keep row label columns sticky when scrolling
  • Wrap Headers — allow long headers to wrap to 2 lines
  • Custom Column Groups — group multiple columns under a single spanning header
  • Title Bold / Italic — style the table title text
⚠️
Resetting Colors: Selecting a new theme preset automatically clears all manually set colors. The theme's default colors take over. To keep custom colors, do not click a theme preset.

Statistical Tests — Detailed Guide

TestWhen to UseOutput
Descriptive Stats Always — first step to understand your data Mean, Median, SD, Min, Max, Quartiles, Skewness
Normality Test Before running t-tests or ANOVA — checks if data is normally distributed Shapiro-Wilk W, p-value, pass/fail interpretation
T-Test Compare means of two groups (e.g., Male vs Female income) t-statistic, p-value, significance stars (*, **, ***)
ANOVA Compare means across 3+ groups (e.g., regional sales) F-statistic, p-value, between/within group variance
Correlation Measure linear relationship between two numeric variables Correlation matrix, coefficient values (–1 to +1)
Regression Predict one variable from others R², coefficients, standard errors, p-values
Cross-tab / Chi-Square Test independence between two categorical variables Chi-square statistic, p-value, expected frequencies
Outlier Detection Find extreme values that may skew analysis List of outlier rows with Z-scores or IQR distance
Frequency Table Summarize a categorical variable's distribution Count, cumulative count, %, cumulative %

Custom Metrics

Create calculated columns from formulas. Access via Insert → Custom Metric.

  1. Click "Insert → Custom Metric"
    Opens the Metric Builder dialog.
  2. Name your metric
    Give it a meaningful name like "Revenue Per Person" or "Conversion Rate".
  3. Write the formula
    Use column names in the formula: e.g., Revenue / Headcount or (Sales - Cost) / Sales * 100. Supports +, –, *, /, parentheses, and basic math functions.
  4. Save and use
    The new metric appears in the Source Panel. Drag it to Values like any other column.
📦

📝

Cell Annotations

Add sticky-note style comments to any table cell.

  1. Right-click any cell in the Live Preview table
    A context menu appears with "Add Annotation" option.
  2. Type your note
    Enter text and choose a highlight color (yellow, red, green, blue).
  3. Annotation appears on the cell
    A colored dot indicator appears. Hover to see the full text.
⚠️
After data changes: If you change the table structure (add/remove rows or columns), the system will check for orphaned annotations and ask you to reconcile or dismiss them.

  • Save Project (Ctrl+S) — saves all tables, configurations, filters, annotations, and metrics to a .tforge project file

Tips & Best Practices

✅
Start simple: Add one field to Rows and one to Values first. Then add more complexity — Columns, filters, second value field — gradually.
✅
Use Combo for survey data: The Combo aggregation (Count + %) is ideal for categorical survey questions — shows raw count and the percentage in one cell on two lines.
✅
Use Bins for age/income: Always bin continuous variables like Age or Income before adding them to Rows — raw continuous values create one row per unique number.
✅
Duplicate before experimenting: Duplicate a well-formatted table before trying a different structure — preserves your work while you experiment.
⚠️
Large files: For files with 100,000+ rows, tabulation may take 2–5 seconds. Use filters to narrow the dataset for faster results.
⚠️
Theme vs. Custom Colors: Selecting a theme preset resets all manual color customizations. Set your theme first, then apply custom colors.
