⚙ Monitor Configuration

Your VPS public IP. Find it in your cloud provider dashboard.
Path to the private key that matches the VPS's ~/.ssh/authorized_keys.
Create at github.com/settings/tokens — needs repo read scope.
First-time SSH setup on Windows:
1. Open PowerShell as Admin and run:
  Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0
2. Generate a key (if you don't have one):
  ssh-keygen -t ed25519 -C "fieldgovern-monitor"
3. Copy key to VPS:
  ssh-copy-id fieldgovern@YOUR_VPS_IP
4. Test: ssh fieldgovern@YOUR_VPS_IP "echo ok"

If your key is from GitHub Actions secrets, export it from your repo secrets and save it to ~/.ssh/fieldgovern_vps, then set the key path above.
