❓ FAQ

Common questions

Does it really work with no internet?

Yes. Forms are cached locally the first time they're loaded. Data is stored in OPFS (Chrome/Android) or IndexedDB (Safari/iOS). Even photos and audio are stored locally until sync. The only internet needed is once to load the form initially — after that, fully offline forever.

Do enumerators need to install anything?

No. FieldPulse is a Progressive Web App (PWA). Enumerators open the URL in Chrome or Safari on any phone. They can optionally "Add to Home Screen" for an app-like icon, but it works directly in the browser with no Play Store or App Store required.

How is data isolated between organizations?

Full multi-tenant isolation at the database level. Every query is filtered by tenant_id. Row-Level Security (RLS) is enforced via SQLAlchemy. No organization can ever see another's data — technically guaranteed at the DB layer, not just application policy.

Can I export to Stata for academic analysis?

Yes. FieldPulse exports to CSV, Stata .dta format (via pandas), and Google Sheets. This is specifically designed for academic and policy research teams who use Stata — a feature SurveyCTO charges extra for on their Professional plan.

What if an enumerator submits the same form twice?

No duplicates. Each submission gets a local_id (idempotency key) generated on the device before submission. If the same submission is pushed twice (e.g., sync interrupted mid-upload), the server detects the duplicate via local_id and silently ignores the second copy.

Can I use FieldPulse with my own branding?

Yes — white-labeling is available on Professional and Enterprise plans. You can set a custom logo, app name, and primary color per organization. Your enumerators see your brand, not "FieldPulse".
