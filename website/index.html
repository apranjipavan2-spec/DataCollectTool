Frequently Asked Questions

Does it really work with no internet? ▾

Yes. Forms are cached locally when first loaded. Data is stored in the browser's OPFS (Chrome/Android) or IndexedDB (Safari/iOS). Even photos and audio are stored locally until sync. The only requirement is one online moment to load the form initially.

Do enumerators need to install anything? ▾

No. FieldPulse is a Progressive Web App (PWA). Enumerators open the URL in Chrome or Safari. They can optionally "Add to Home Screen" for an app-like experience, but it works fine directly in the browser too.

How is data isolated between organizations? ▾

Full multi-tenant isolation at the database level. Every query is filtered by tenant_id. Row-Level Security (RLS) is enforced via SQLAlchemy. No org can ever see another org's data — technically guaranteed, not just policy.

Can I export data to Stata for analysis? ▾

Yes. FieldPulse exports to CSV, Stata .dta format (via pandas), and Google Sheets. This is specifically built for academic and policy research teams who use Stata for analysis — a feature SurveyCTO charges extra for.

What happens if an enumerator submits the same form twice? ▾

No duplicates. Each submission gets a local_id (idempotency key) generated on the device. If the same submission is pushed twice (e.g., sync interrupted), the server detects the duplicate and ignores the second copy.
