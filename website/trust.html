At a glance

Data processor roleFieldGovern (operated by Dataworx) processes data on your instructions — you remain the data fiduciary.
Tenant isolationDatabase-level row-level security via a restricted, non-superuser database role — not application-code filtering alone.
Encryption in transitTLS 1.2+ and HSTS enforced on every connection.
Audit loggingTamper-evident, hash-chained audit log with automated anomaly detection (repeated failed logins, off-hours access).
ConsentItemised, versioned notice with per-purpose consent (survey / photo / audio / GPS), shown before the first question.
Data-principal rightsA dedicated workflow to log, search, act on, and close access/correction/erasure/portability requests, with SLA tracking.
Breach responseA written plan with defined roles, severity levels, and the CERT-In 6h / customer 24h / Board 72h timelines.
Self-hostingFully self-hostable via Docker Compose on infrastructure you control, if you'd rather not use our hosted service.
